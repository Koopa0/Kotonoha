# 言の葉 · Kotonoha

[English](README.md) · **繁體中文** · [日本語](README.JP.md)

為繁體中文讀者設計的日語閱讀練習 app。從熟悉平假名、片假名開始，
逐步練習單字、短句與漢字讀音。每回練習簡短，介面安靜，不追逐分數、連續天數或獎勵。

## 練習功能

- **手解き — 學假名。** 逐行認識 208 個平假名與片假名學習項目，包含濁音、半濁音與拗音。
- **今日の稽古 — 複習假名。** 根據學習紀錄選題，練習已接觸的假名；新假名從手解き學起。
- **目利き — 辨別相似假名。** 練習シ／ツ、ね／れ／わ等容易混淆的字形。
- **手習い — 紙上默寫。** 依提示在自己的筆記本寫出假名，再揭曉答案並自行核對。
- **五十音図 — 查假名。** 瀏覽假名，查閱與聆聽讀音。
- **渡し舟 — 學單字。** 先聽單字，再揭曉假名並試著讀出來。
- **文字起こし — 聽寫單字。** 聽音後用假名磚拼出單字。
- **黙読 — 讀短句。** 先自行閱讀，再揭曉讀音與意思。
- **漢字の声 — 練漢字讀音。** 學習並回想 app 詞句中的漢字讀音。
- **名残の仮名 — 讀漢字句。** 練習漢字與假名混寫的句子；隨對應讀音逐漸熟悉，假名標音會淡出。
- **歩み — 看學習狀況。** 查看接觸過的假名範圍、目前狀態，以及累積足夠練習紀錄後觀察到的字形混淆。

## 發音與本機資料

發音使用裝置的日語文字轉語音（TTS）引擎；語音可用性與離線播放取決於已安裝的語音。

學習進度與練習紀錄儲存在裝置上，無須帳號，也沒有廣告。

## 平台

以 Flutter 打造，支援 Android 與 iOS。
