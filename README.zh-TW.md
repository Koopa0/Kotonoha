# Kotonoha 言の葉

[English](README.md) · **繁體中文** · [日本語](README.JP.md)

> 沉靜、極簡的日文假名閱讀夥伴。

Kotonoha(言の葉)是一個為成人設計的日文假名閱讀練習。每天安靜的兩分鐘,建立
「看到字形就反射出聲音」的直覺 —— 涵蓋全部 208 個平假名與片假名 —— 再用小詞在脈絡中
真正讀起來。

它刻意不急不躁。沒有連續天數、沒有徽章、沒有 XP、沒有吉祥物、沒有彩帶動畫。只有你、
假名,和一個像筆記本一樣安靜的練習空間。整個 app 以 Flutter 打造。

## 一天的樣子

打開 app,點「**今天的練習**」—— 一段自適應的練習,自動混合「該複習的」、「比較弱的」、
和「一點點新的」。什麼都不用設定,直接開始。兩分鐘後,就結束了。

## 內容

- **全部 208 個假名** —— 平假名與片假名,含濁音、半濁音、拗音,以循序課程一行一行學。
- **今天的練習** —— 一段會依你自己的資料自動組成的自適應練習,你永遠不必選模式。
- **易混淆練習** —— 專練長得像、容易搞混的假名(ね / れ / わ、さ / ち …)。
- **讀詞練習** —— 用你已解鎖的假名讀小詞,配發音,在脈絡中熟悉。
- **手寫默寫** —— 搭配實體習字本:看題目 → 在紙上寫 → 翻開看答案 → 自評。
- **原生發音** —— 點任何假名或詞就能聽(日語語音合成)。
- **安靜的進度** —— 一眼看到正確率、哪些假名熟、哪些還弱,不帶任何罪惡感。
- **天生私密** —— 無帳號、無網路、無廣告,一切都留在你的裝置上。
