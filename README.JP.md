# 言の葉 · Kotonoha

[English](README.md) · [繁體中文](README.zh-TW.md) · **日本語**

繁体字中国語の読者のための、日本語の読みを練習するアプリです。
ひらがな・カタカナに慣れるところから、単語、短い文、漢字の読みへ進みます。
一回の練習は短く、画面は静かに。点数や連続記録、報酬を追いかける仕組みはありません。

## 練習できること

- **手解き — かなを学ぶ。** 濁音・半濁音・拗音を含む、ひらがな・カタカナの208の学習項目を一行ずつ。
- **今日の稽古 — かなを復習する。** 学習記録に応じて、すでに出会ったかなを練習します。慣れたかなは選択肢を離れ、読みを思い出してから、すでに出会った語と読める短い文へ進みます。新しいかなは手解きで学びます。
- **目利き — 似たかなを見分ける。** シ／ツ、ね／れ／わなど、取り違えやすい字形を練習します。
- **手習い — 紙に書いて思い出す。** お題に沿って自分のノートにかなを書き、答えを表示して確かめます。
- **五十音図 — かなを調べる。** 一覧からかなを探し、読みと音声を確認します。
- **渡し舟 — 単語に出会う。** まず音を聴き、かなを表示して、自分でも読みます。
- **文字起こし — 単語を書き取る。** 聴いた単語をかなのタイルで組み立てます。
- **黙読 — 短い文を読む。** 先に自分で読み、そのあと読み方と意味を確認します。
- **漢字の声 — 漢字の読みを練習する。** アプリの単語や文に出てくる漢字の読みを学び、思い出します。
- **名残の仮名 — 漢字かな交じり文を読む。** 対応する読みが身につくにつれて、ふりがなが薄くなります。
- **歩み — 学習の様子を見る。** 出会ったかなの範囲と現在の状態を確認します。練習記録が十分に集まると、繰り返している字形の取り違えも表示します。

## 音声と端末内のデータ

発音には端末の日本語読み上げ（TTS）エンジンを使います。利用できる音声や
オフラインでの再生は、インストール済みの音声によって異なります。

学習の進捗と練習記録は端末に保存します。アカウントは不要で、広告もありません。

## 対応プラットフォーム

Flutter 製。Android と iOS に対応しています。
