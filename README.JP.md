# Kotonoha 言の葉

[English](README.md) · [繁體中文](README.zh-TW.md) · **日本語**

> かなを読むための、静かでミニマルな相棒。

言の葉(ことのは)は、日本語のかなを「読む」ための、大人向けの練習アプリです。一日
たった二分。文字を見た瞬間に音になる——その反射を、ひらがな・カタカナ全208字でじっくり
育てます。やがて、短い言葉を文脈の中で自然に読めるように。

急かしません。連続記録もバッジも、XP も、マスコットも、にぎやかな演出もありません。
あるのは、あなたと、かなと、ノートのように静かな練習の時間だけ。アプリは Flutter で
作られています。

## 一日の流れ

アプリを開いて「**今日の練習**」をタップするだけ。その日にちょうどいい一回の練習が、
「そろそろ復習したいもの」「少し苦手なもの」「ほんの少し新しいもの」を自動で混ぜて
用意されています。設定はいりません。二分ほどで、おしまい。

## できること

- **かな全208字** —— ひらがな・カタカナに加え、濁音・半濁音・拗音まで。一行ずつ、
  順番に学べます。
- **今日の練習** —— あなたのデータから自動で組み立てる適応型の練習。モードを選ぶ
  必要はありません。
- **似ているかなの練習** —— 見分けにくいかな(ね / れ / わ、さ / ち …)を集中的に。
- **読みの練習** —— 覚えたかなでできた短い言葉を、音と一緒に、文脈の中で読みます。
- **手書きの想起** —— 紙の練習帳と一緒に。お題を見て紙に書き、答えを見て、自分で
  採点します。
- **ネイティブ音声** —— かなや言葉をタップすると読み上げます(日本語 TTS)。
- **静かな進捗** —— 正答率や、得意・苦手なかながひと目で分かります。責めません。
- **プライベート設計** —— アカウントも通信も広告もなし。すべて端末の中だけで完結します。

## 対応プラットフォーム

Flutter 製。**Android** と **iOS** に対応しています。
