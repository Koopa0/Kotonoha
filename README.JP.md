# 言の葉 · Kotonoha

[English](README.md) · [繁體中文](README.zh-TW.md) · **日本語**

> やまとうたは、人の心を種として、よろづの言の葉とぞなれりける。

---

言の葉(ことのは)は「言葉の葉」。冒頭の一首は紀貫之『古今和歌集』の仮名序(905 年頃)——
心という種から、よろづ(万)の葉へ。ことばは作られ・鍛えられるのではなく、花が咲くように
生(な)る。このアプリがしたいのも、それです——言語を「訓練」するのではなく、葉を幾枚か、
静かに育てること。

だから急かしません。そして「**読む**」ことに専念します。一日たった数分、文字を見た瞬間に
音になる反射を、ひらがな・カタカナ全208字でじっくり育て、やがて短い言葉や文へ、漢字の
読みの入り口へ。連続記録もバッジも、XP も、マスコットも、にぎやかな演出もありません——
あるのは、あなたと、かなと、ノートのように静かな時間だけ。雨あがりの庭の青磁色が、和紙の
上に落ちる。Flutter 製で、すべて端末の中だけで動き、アカウントもいりません。

名前には、より古い層もあります。上代では「言(こと)」と「事(こと)」は同じ音——
ことばを発することは、その事に触れること。これが「言霊(ことだま)」の根です。そして葉は
散る——ことばも葉のように、季節をもつ。その静かな物の哀れが、アプリ全体の基調です。

## 一日の流れ

アプリを開いて「**今日の稽古**」をタップするだけ。その日にちょうどいい一回の練習が、
「そろそろ復習したいもの」「少し苦手なもの」「ほんの少し新しいもの」を自動で混ぜて
用意されています。設定はいりません。数分ののち、練習は「**凪**」へ——静かで、言葉の
ない締めくくりに落ち着きます。

## できること

それぞれの練習には静かな名前があり、アプリは何をするのかをそっと言葉で添えます。

- **手解き — かなを学ぶ。** ひらがな・カタカナ全208字。濁音・半濁音・拗音まで、一行ずつ
  順番に。
- **今日の稽古 — その日の練習。** あなたのデータから自動で組み立てる適応型の一回。
  モードを選ぶ必要はありません。
- **渡し舟 — わたしぶね。** 目より耳が先を行くあなたへ。まず言葉を聴き、余韻の中で
  かなが浮かび上がるのを見て、自分で読み返す。音を、その文字へと渡します。
- **文字起こし — ディクテーション。** 言葉を聴いて、かなのタイルから組み立てる。
  認識だけでは得られない「書き起こす」練習。
- **黙読 — 文を読む。** 短い文を心の中で読み、それから読み・意味・音声をあらわします。
- **目利き — 見分け。** 見分けにくいかな(シ / ツ、ね / れ / わ …)を集中的に。
- **手習い — 紙に書く。** 紙の練習帳と一緒に。お題を見て紙に書き、答えを見て、自分で
  採点します。(画面認識はなし、紙だけ。)
- **漢字の声 — 漢字の読み。** 漢字に日本語の声を。手がかりから音読・訓読を思い出します。
- **名残の仮名 — 漢字の文。** 漢字とふりがなのある本物の文を読む——ふりがなは、
  読みが身につくにつれて、ひとつずつ静かに消えていきます。
- **五十音図 — かなの一覧。** 音節表の全体を眺め、どのかなも詳細をタップで。
- **歩み と 自画像 — 静かな振り返り。** ここまでの道のりと、どのかなを取り違えやすいか、
  読む速さがどう落ち着いてきたか——そっと映す自画像を。責めることなく。

かな・言葉・文は、どれもタップすれば日本語の音声で読み上げます。

## プライベート設計

アカウントも通信も広告もなし。進捗も練習の記録も、すべて端末の中だけに。

## 対応プラットフォーム

Flutter 製。**Android** と **iOS** に対応しています。
